# Changelog

- v0.1.0: first release. Tokens ported from the Clip FX prototype. Primitives: Button (+ FileButton, ButtonRow), IconButton, Toggle, Slider, Select, Card, Field, Sheet, Tabs, Toast, Swatch, ProgressBar, Dock, TopBar, Dot.
- v0.2.0: new primitives Panel, PanelHeader, CardRow, ControlStack, Stack, Description, PickGrid, ListRow, TextInput, SheetPanel; Swatch `empty` variant; fonts.css now ships Latin subsets only; text primitives set their own font-family (fixes serif text in Field goldens); new tokens (colour-white, space-tight, size-hatch-_, layout-sheet-_).
- v0.2.0 (cont.): Button `size="sm"` (compact, for panel headers); Card is content-box 102x82 like the reference (was 100x80).
